# PSP_Temp_Anisotropy
For this to work several key python packages are needed. 'cdflib', 'xarray', and 'pyspedas'

In order to execute the 'run_spc_temperature_anisotropy.py' script you will need to make a directory called Fit_Data use:

mkdir Fit_Data

The run_spc_temperature_anisotropy will generate a cdf file containing all temperature anisotropy values.
